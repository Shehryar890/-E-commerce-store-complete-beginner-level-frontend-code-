 simple e-commerce frontend project built with React and Redux Toolkit.

This project was created in 2024 as a practice project while learning React and modern frontend development. It contains multiple e-commerce-style UI pages with reusable components, product sections, navigation, and cart-related functionality.

The main focus of the project was to practice building clean, component-based interfaces and managing shared application state using Redux Toolkit.

Built with: React, Redux Toolkit, JavaScript, React Router, HTML, CSS
